# Windows Desktop Fluent UI Guidelines

- **Fluent Design Standards**: Enforce desktop-optimized layout scaling, multi-pane grids, and responsive window frame handling.
- **Desktop Focus & Shortcuts**: Ensure full keyboard navigation (Tab and Arrow keys) with high-visibility focus indicators.
- **High-Density Data Views**: Design multi-column sortable lists, poster grids, and media detail views scaled for large desktop monitors.
